## 使用本仓库之前必须核实

1. 目前是否仍部署、是否有真实客户/报名订单，以及域名、数据库和数据保管责任人。
2. 支付提供方、支付回调、退款、回执及账务一致性在当前环境是否有独立验收记录。
3. 历史演示账号、默认凭据及开发密钥是否已经清除、禁用或轮换；核实鉴权与个人信息访问权限。
4. 如确已停用，先备份历史资料和数据映射，再由业务负责人决定归档；不要直接删除代码或数据库。
